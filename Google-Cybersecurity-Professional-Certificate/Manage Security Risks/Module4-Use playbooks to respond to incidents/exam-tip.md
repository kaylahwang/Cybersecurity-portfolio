# Playbooks Exam Tips


## Playbook Basics

Remember:

Playbook = Step-by-step response guide


Important:

❌ Playbooks are NOT permanent documents

✅ Playbooks are living documents that are updated frequently


---

# Incident Response Phases


## Preparation

Before incident:

- Create procedures
- Train employees
- Prepare resources


## Detection and Analysis

Think:

"Find and investigate"

Examples:

- Analyze SIEM alerts
- Review logs
- Validate suspicious activity


## Containment

Think:

"Stop the damage"

Examples:

- Isolate systems
- Limit attacker movement


## Eradication and Recovery

Think:

"Remove and restore"

Examples:

- Remove malware
- Restore from clean backups


## Post-Incident Activity

Think:

"Learn and improve"

Examples:

- Root cause analysis
- Update procedures
- Improve security posture


## Coordination

Think:

"Communicate"

Examples:

- Report incidents
- Share information with required organizations


---

# SIEM vs Playbook vs SOAR


SIEM:

Collects logs and generates alerts.


Playbook:

Provides instructions for responding.


SOAR:

Automates repetitive response actions.


---

# Common Exam Traps


Question:
"Analyze log data and metrics after SIEM alert"

Answer concept:
Detection and Analysis


Question:
"Restore data using clean backup"

Answer concept:
Eradication and Recovery


Question:
"Prevent further damage"

Answer concept:
Containment


Question:
"Improve security after incident"

Answer concept:
Post-Incident Activity
