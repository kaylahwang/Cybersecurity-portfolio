# Module 3 Exam Tips


## SIEM Functions

Remember:

SIEM =
Collect logs
+
Analyze events
+
Detect threats


## SIEM Types

Self-hosted:
- Own infrastructure
- More control

Cloud-hosted:
- Vendor manages infrastructure

Cloud-native:
- Designed for cloud scalability

Hybrid:
- Combination of self + cloud


## Dashboard Differences

Splunk:
Security posture → SOC monitoring

Incident review → Timeline investigation

Risk analysis → User/device/IP risk


Chronicle:
IOC Matches → Threat indicators

User Sign-in Overview → Login behavior


## Open-source vs Proprietary

Open-source:
- Public source code
- Customizable
- Community driven

Proprietary:
- Company owned
- Paid usage
- Limited modification
