# Module 3 Glossary


## SIEM
Security Information and Event Management.

A platform that collects and analyzes security logs.


## Log
A record of events occurring within systems or networks.


## Metrics
Technical measurements used to evaluate performance.

Examples:
- Response time
- Availability
- Failure rate


## SOAR
Security Orchestration, Automation and Response.

Uses automation to respond to security incidents.


## Chronicle
Google cloud-native SIEM platform.


## Splunk Enterprise
Self-hosted SIEM solution.


## Splunk Cloud
Cloud-hosted SIEM solution.


## Playbook
A documented procedure describing operational actions.
