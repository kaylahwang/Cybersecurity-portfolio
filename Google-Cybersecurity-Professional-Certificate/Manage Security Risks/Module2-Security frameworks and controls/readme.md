# Key Concepts

## Security Frameworks

Security frameworks are guidelines used to create security plans that help organizations mitigate risks and protect data and privacy.

Frameworks provide:
- Security best practices
- Risk management guidance
- Compliance support
- A structured approach to cybersecurity

Examples:
- NIST Cybersecurity Framework (CSF)
- NIST Risk Management Framework (RMF)
- ISO/IEC 27001
- Cyber Threat Framework (CTF)

---

## Security Controls

Security controls are safeguards designed to reduce specific security risks.

Controls help organizations:
- Prevent security incidents
- Detect threats
- Correct security issues
- Protect critical assets

Types of security controls:

### Physical Controls
Examples:
- Security guards
- CCTV cameras
- Locks
- Access cards

### Technical Controls
Examples:
- Firewalls
- Multi-factor authentication (MFA)
- Antivirus software
- Encryption

### Administrative Controls
Examples:
- Security policies
- Authorization processes
- Separation of duties
- Asset classification

# CIA Triad

The CIA Triad is a foundational security model used to design security policies and systems.

## Confidentiality

Ensures that only authorized users can access information.

Examples:
- Least privilege
- Access control
- Authentication

Key question:
> Who should have access?

---

## Integrity

Ensures that data remains accurate, authentic, and reliable.

Examples:
- Cryptography
- Encryption
- Data validation

Key question:
> Can we trust this data?

---

## Availability

Ensures that authorized users can access systems and information when needed.

Examples:
- Backup systems
- Disaster recovery
- System maintenance

Key question:
> Can users access resources when required?

---

# NIST Cybersecurity Framework (CSF)

The NIST CSF is a voluntary framework consisting of standards, guidelines, and best practices used to manage cybersecurity risk.

The six core functions are:

1. Govern
2. Identify
3. Protect
4. Detect
5. Respond
6. Recover

## Functions Overview

| Function | Purpose |
|---|---|
| Govern | Establish cybersecurity strategy, policies, roles, and risk management |
| Identify | Understand assets, risks, and policies |
| Protect | Implement safeguards, training, and security controls |
| Detect | Identify security incidents and improve monitoring |
| Respond | Contain, analyze, and manage incidents |
| Recover | Restore affected systems and improve resilience |

# OWASP Security Principles

OWASP principles help security professionals reduce vulnerabilities and improve secure development practices.

Important principles:

- Minimize attack surface area
- Principle of least privilege
- Defense in depth
- Separation of duties
- Keep security simple
- Fix security issues correctly
- Establish secure defaults
- Fail securely
- Don't trust services
- Avoid security by obscurity

---

# Security Audits

A security audit is a review of an organization's:

- Security controls
- Policies
- Procedures

against defined expectations.

Security audits help organizations:

- Identify risks
- Evaluate control effectiveness
- Improve security posture
- Meet compliance requirements

Audit communication should include:

- Audit scope and goals
- Identified risks and compliance requirements
- Recommendations for improving security posture

# Key Takeaways

- Frameworks provide security guidance; controls provide specific protection measures.
- The CIA Triad helps organizations balance confidentiality, integrity, and availability.
- NIST CSF provides a structured approach to managing cybersecurity risk.
- OWASP principles promote secure design and development practices.
- Security audits evaluate whether controls are effective and aligned with security goals.
- Effective cybersecurity requires continuous improvement of an organization's security posture.
