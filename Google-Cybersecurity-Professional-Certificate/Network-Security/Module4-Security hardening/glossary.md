# Module 4 - Security Hardening: Glossary

| Term | Definition | In Practice |
|---|---|---|
| Cloud Computing | On-demand access to shared computing resources | Infrastructure managed by cloud providers |
| IAM | Identity and Access Management processes and technologies | Controls authentication and authorization |
| Cloud Migration | Moving systems or services to a cloud environment | Requires secure configuration and planning |
| Attack Surface | Total number of possible entry points into a system | Expands as additional services are added |
| Zero-Day Attack | An attack exploiting an unknown vulnerability | Often difficult to detect before disclosure |
| Flow Logs | Records of network communications | Used for monitoring and investigations |
| Visibility | Ability to observe system and network activity | Helps identify threats and anomalies |
| Security Hardening | Reducing vulnerabilities through security controls | Improves security posture |
| CSP | Cloud Service Provider | AWS, Azure, Google Cloud |
| Shared Responsibility Model | Security responsibilities divided between CSP and customer | Infrastructure vs workload security |
| NIST CSF | Framework for managing cybersecurity risk | Based on Identify, Protect, Detect, Respond, Recover |
| Risk Assessment | Process of identifying and evaluating security risks | Supports security planning |
| Access Control | Restricting access to authorized users and resources | Enforced through IAM and policies |
| Protective Technology | Security solutions used to defend systems | Firewalls, IDS, IPS |
| IDS | Intrusion Detection System | Detects suspicious activity |
| IPS | Intrusion Prevention System | Detects and blocks threats |
