# Secure Against Network Intrusions

## Overview

In this module, I learned how network intrusion attacks compromise systems, disrupt services, and impact business operations. I focused on identifying attack patterns, analyzing network traffic, and investigating security incidents using packet analysis tools.

---

## Security Concepts Learned

### Network Interception Attacks

- Packet Sniffing
- IP Spoofing
- On-Path Attacks
- Replay Attacks
- Smurf Attacks

### Denial of Service Attacks

- DoS
- DDoS
- SYN Flood
- ICMP Flood
- Ping of Death

### Network Security Concepts

- TCP Three-Way Handshake
- Traffic Monitoring
- Network Availability
- Defense-in-Depth

---

## Tools Used

- tcpdump
- Wireshark
- TCP Traffic Logs
- HTTP Logs

## Hands-On Activities

### Traffic Analysis

- Investigated packet captures using tcpdump
- Identified source and destination IP addresses
- Analyzed network traffic patterns

### SYN Flood Investigation

- Examined TCP handshake behavior
- Identified abnormal SYN packet activity
- Investigated web server timeout issues
- Determined the root cause of service disruption

### Incident Reporting

- Analyzed security evidence
- Documented attack findings
- Recommended mitigation strategies

## Real-World Case Study

### DNS DDoS Attack (2016)

Key lessons:

- Botnets enable large-scale attacks
- DNS infrastructure is a critical service
- DDoS attacks impact availability and business operations
- Resilient infrastructure improves recovery
